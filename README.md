Solara Bay — an open-world crime game in the spirit of GTA 6, built for the make.fun gta6-01 bounty. Dante Cole is back in a sun-soaked coastal city with empty pockets and a fixer who never forgets a debt. Explore a 7x7 road-grid city on foot and by car, steal cars, dodge traffic and pedestrians, outrun a 0–3 star wanted level with police cruisers that chase, ram and arrest, fight with a pistol, and run three story missions for Rosa Delgado: Wheels Up, The Package and Heat Wave. HUD with a live minimap, health, money, speed and objectives; synth sound; particles; title, pause, wasted, busted and complete screens; localStorage save with Continue.

## Run it

```sh
cd game && python3 -m http.server 8080
# open http://localhost:8080 in a desktop browser
```
